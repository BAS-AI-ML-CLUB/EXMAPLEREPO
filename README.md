# BAS AI/ML Club – Weekly Notebook Starter

Welcome to the **BAS AI/ML Club** template repository.  
Each member should click **Use this template** to create their own personal semester notebook workspace.

## Getting Started

1. Open `notebooks/00_template.ipynb` in **Google Colab**:
   - Go to **File > Open notebook > GitHub**
   - Paste your repo URL and open `notebooks/00_template.ipynb`

2. Install dependencies (if running locally):
   ```bash
   pip install -r requirements.txt
   ```

3. Each week, duplicate the template notebook and rename it using the naming convention in `notebooks/README.md`.

## API Keys & Secrets

- **Never commit API keys** to GitHub.
- Copy `.env.example` to `.env`.
- `.env` is already gitignored.
- Load env vars in Python with `python-dotenv`.
