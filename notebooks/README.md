# Weekly Notebook Naming Convention

Create exactly **one notebook per week** using this naming format:

```text
week01_ml_basics.ipynb
week02_pandas.ipynb
week03_regression.ipynb
week04_classification.ipynb
week05_clustering.ipynb
week06_pca.ipynb
week07_evaluation_metrics.ipynb
week08_hyperparameter_tuning.ipynb
week09_prompting.ipynb
week10_langchain_agents.ipynb
week11_structured_output.ipynb
week12_langgraph.ipynb
week13_rag_embeddings.ipynb
week14_rag_pipeline.ipynb
week15_ai_failures.ipynb
week16_guardrails.ipynb
week17_capstone_build.ipynb
week18_demo_day.ipynb
```

Consistent naming makes the full semester progression instantly clear to anyone opening the repo (including a college admissions reader) with no extra explanation needed.
